# 事项跟踪

## 本地工作

- 思考、调查、试错和临时清单保存在 .scratch/<feature>/。
- .scratch/ 不提交到 Git。
- 技能产生的任务与规格默认先写成本地草稿。

## GitHub Issues

- 发布适合公开协作的缺陷、功能需求和明确开发任务。
- 发布前整理问题背景、预期行为和验收标准，并脱敏。
- 用户明确要求发布，或已有相关授权时，才通过 gh 发布。
- 已发布事项以 Issue 为正式状态来源，本地草稿引用对应编号。
- 仓库以实际 Git remote 为准；未配置时不擅自创建远端仓库。
- 多行正文写入临时文件，通过 gh 的 --body-file 参数提交，保留真实换行。

PRs as a request surface: no.
