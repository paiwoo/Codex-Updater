# 聚焦官方 Windows 客户端，并分别报告更新结果

2026-10-23 用户确认：首版面向 Windows 官方稳定版 Codex，以 x64 为首个实测平台，Codex++ 不作为运行前提。现有两个工具将包更新与第三方增强服务绑定，导致安装成功仍被报告为整个更新失败；首版分别报告包部署、目标版本运行和更新提示状态，第三方兼容性不决定核心更新结果。

工具默认只读诊断，由用户点击修复、查看具体动作并得到保存工作的提醒后再执行更新；首版手动运行。这样减少自动化覆盖范围，但能够明确更新对运行中工作的影响。ARM64 在完成实机验证后标记支持。
