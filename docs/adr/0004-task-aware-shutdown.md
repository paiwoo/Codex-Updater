# 更新前检查任务，空闲自动退出

2026-10-26 用户确认：更新前检查 Codex 是否正在执行任务；空闲时直接结束 Codex，无需额外的强制退出提醒；有任务时才允许用户选择是否中断。更新后启动并核对目标版本。本决策替代先前“所有强制退出均单独确认”的交互约定，保留首次查看修复方案。

选择读取本机正在持有的会话锁与任务生命周期标记，不根据 CPU、进程存在或聊天存在猜测执行状态；只处理当前用户、当前 Windows 会话内已识别的应用包进程及关联后台引擎。未知格式或无法可靠检测时等待确认，接受内部格式变更后可能增加一次确认的限制，以免中断任务；不保存或导出聊天文本。结束进程前复查任务，自动恢复不沿用上次中断任务的授权。

实机复现显示进程结束后 Windows 仍可能报告旧包活动服务。通过前述检查后，部署使用 Windows 的 `ForceTargetApplicationShutdown` 关闭目标包残留服务，保留签名校验与同包升级；不采用会关闭依赖应用的广泛关闭选项。占用失败重新检测并最多重试一次。
