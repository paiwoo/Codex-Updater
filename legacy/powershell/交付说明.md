# 在另一台电脑使用

本包是 Windows PowerShell 源码工具，无需安装 Python、Node.js 或 Rust。请先完整解压到当前用户可写的本地固定文件夹，不要直接在压缩包内运行。目录中的三个 `.ps1` 必须与 `.cmd` 保持在一起。

## 使用顺序

1. 目标电脑需已安装官方稳定版 Codex（包名 `OpenAI.Codex`）及 Codex++。此工具用于更新已有安装，不负责首次安装。
2. 双击 `SelfTest.cmd`。它仅运行本地逻辑自检，不联网、不安装、不关闭 Codex、不创建计划任务。
3. 保存工作，结束其他 Codex 任务，再双击 `Update-Codex.cmd`。如出现系统 UAC，请使用同一 Windows 账户授权。
4. 等待最终结果；可双击 `Check-Codex.cmd` 检查当前运行版本、增强服务与更新提示。该检查不安装、不重启，但可能生成本目录中的诊断文件。

以后继续双击同一目录的更新入口。工具根据当前用户、Windows 包注册信息和 Codex++ 安装位置查找路径，无需修改原电脑的用户名或盘符。

## 运行前提

- Windows 桌面环境，Windows PowerShell 5.1、`curl.exe`、Appx 模块和任务计划程序可用。
- 当前用户允许创建按需计划任务，可访问官方更新服务器。
- 当前处理 x64 / arm64 包；ARM64 未做实机安装测试。
- 更新期间保持 Windows 登录，不要关机。窗口检查需要可访问的桌面及正常显示的 Codex 窗口。
- 安装任务或 Codex++ worker 运行时，不要移动、重命名或删除解压文件夹。

## 更新来源与进度

工具交叉核对官方稳定版下载列表与客户端使用的 Store 更新清单，选择较新版本；优先使用 Windows 已暂存的新包，否则下载官方 MSIX。身份、版本、架构及签名检查通过后才关闭客户端。

控制台每秒显示阶段、总耗时、本阶段耗时、后台进程是否存活、上次状态更新时间。下载与安装在获得真实数据时显示大小或百分比，其余阶段显示等待状态。进程存活只说明尚未退出，不等于每秒都取得进展。

计划任务由 Windows 独立运行，客户端退出不会中断安装。只有运行包、增强服务和两次窗口检查都通过，才记录 `complete`；不会隐藏更新提示来伪造成功。

## 已知限制与验证范围

**尚未在另一台电脑完成真实安装验证。** 交付检查包含脚本语法、现有自检及含中文和空格的解压路径，不执行真实更新。

原电脑曾成功完成独立任务安装、新包启动和提示消失验证，但 **2026-10-23 最近一次记录为：Codex 安装成功，Codex++ 最终启动验证失败**。本包保留真实错误检查，不承诺当前或后续所有 Codex++ 版本兼容。

旧版独立启动器使用 `--app-path`；Codex++ 1.9 及之后当前使用内部 `--codex-plus-multi-worker` 入口。此入口不是稳定的公开接口，后续版本可能改变参数或增加实例身份校验。遇到“Codex++ did not report running…”时，可先用 Codex++ 自身界面启动，再运行 `Check-Codex.cmd`。若仍失败，需要针对该 Codex++ 版本修正启动接口。

若 Store 清单已更新，但新包未暂存、官方下载地址也未发布，下载可能失败。官方改变更新源、签名或提示文案时需调整脚本。未来发布新版后，正常更新提示仍可能再次出现。

## 共享与停用

压缩包只含源码、入口和文档，不含原电脑的认证、备份、会话、日志、运行结果或缓存安装包。

使用后生成的 `logs/backup-*` 可能包含 `auth.json` 和密钥，**不要把运行后的整个目录原样转发**。分享问题时先检查日志是否含个人路径或敏感信息。

默认计划任务名为 `Codex-Independent-Update`，没有定时触发器。重复双击会接入正在运行的任务；不要同时从多个解压目录启动，它们会共用任务名。停用时先确认没有安装任务运行，再在 Windows 任务计划程序删除该任务；删除文件夹不会自动删除任务。

## 源码结构

| 文件 | 职责 |
| --- | --- |
| `Update-Codex.ps1` | 查询更新、独立任务、启动与验证、进度显示 |
| `Install-CodexPackage.ps1` | 安装或注册已暂存包、Windows 部署进度 |
| `Inspect-CodexWindow.ps1` | 只读检查客户端窗口的更新按钮 |
| `Update-Codex.cmd` | 双击更新入口 |
| `Check-Codex.cmd` | 双击运行状态检查 |
| `SelfTest.cmd` | 双击本地逻辑自检 |

具体命令行与输出文件见 `README.md`。
