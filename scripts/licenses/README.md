These upstream license texts supplement dependencies whose published archives declare a license but omit its text. The notice collector includes them in Windows release artifacts.

- `alloc-stdlib.txt`: Dropbox BSD-3-Clause license, https://raw.githubusercontent.com/dropbox/rust-alloc-no-stdlib/0a81fd6928ea3b33c8cd484aa4575d50ffb98012/LICENSE (crate 0.3.0 source commit).
- `webview2-rs.txt`: Bill Avery MIT license, https://raw.githubusercontent.com/wravery/webview2-rs/edc2caf886175ccaebe86078c9cfe1ae2a187328/LICENSE (webview2-com 0.39.1 source commit; applies to the three webview2-rs crates).
- `react-remove-scroll-bar.txt`: Anton Korzunov MIT license, https://raw.githubusercontent.com/theKashey/react-remove-scroll-bar/8ca9ba5ea52de03308fe8ced94f7b159a44d28ff/LICENSE (upstream license snapshot; package 2.3.8 declares MIT and the same author).
- `selectors.txt`: MPL-2.0 text from https://raw.githubusercontent.com/spdx/license-list-data/v3.27.0/text/MPL-2.0.txt. Selectors 0.38.0 source files retain their MPL notices; its unmodified corresponding source is available at https://crates.io/crates/selectors/0.38.0 and https://github.com/servo/stylo/tree/572ecba2d1600e7c3d490586692a209faf703baa/selectors .

For MPL-covered dependencies, including selectors, obtain the unmodified corresponding source from the exact version on crates.io or the source revision recorded in the crate. The application does not change those source files. Root project licensing does not replace dependency licensing.
